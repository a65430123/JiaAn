# 家安工程行｜Google 協作平台嵌入區塊

用來製作「家安工程行」網站上需要特殊設計或互動的區塊。網站主體（導覽列、頁面、地圖、表單）用 Google 協作平台內建功能做，這裡只負責 10 個嵌入區塊。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `editor.html` | **區塊編輯器**。用瀏覽器直接開啟，改文字、增減項目、即時預覽桌機／手機，再按「複製嵌入程式碼」。 |
| `blocks/*.html` | 用範例內容輸出的 10 個區塊，可直接貼進協作平台。 |
| `src/editor-body.html` | 編輯器原始碼（修改這個檔案）。 |
| `tools/build.js` | 由原始碼產生 `editor.html` 與 `blocks/`，並實測每個區塊的高度。執行：`node tools/build.js`（需要 Playwright）。 |

## 編輯器怎麼用

1. 用 Chrome 開啟 `editor.html`。
2. 先到「品牌資訊」填電話、LINE 加好友網址、營業時間、經驗年數、商城網址、Google 表單網址。這些會自動套用到所有區塊。
3. 左邊選區塊，改內容。清單類的內容（服務、評價、商品、問答……）都可以新增、複製、刪除、上下移動。
4. 右邊預覽可切換「桌機 1000px／手機 360px」，上方會顯示依目前內容實測的「建議嵌入高度」。
5. 按「複製嵌入程式碼」，到協作平台：插入 → 嵌入 → 嵌入程式碼 → 貼上 → 下一步 → 插入，再拖曳框線調整高度。
6. 內容自動存在這台電腦的瀏覽器。換電腦前請到「備份與還原」複製備份文字。

> 範例數字、評價、商品與優惠活動都只是示意，上線前請換成真實資料。不要放虛構的客戶評價。

## 10 個區塊

高度是用範例內容在桌機 1000px／手機 360px 實測的結果（已加約 16px 緩衝）。內容改了，請以編輯器顯示的數字為準。協作平台的嵌入框桌機與手機共用同一個高度，請設成兩個數字中較大的那個。

| # | 區塊 | 用途 | 建議高度（桌機／手機） | 放置位置 |
| --- | --- | --- | --- | --- |
| 1 | 信任數字列 | 年資、完工件數、好評、保固，進入畫面時數字滾動 | 280／430 | 首頁頁首大圖下方 |
| 2 | 服務項目卡片 | 水電、弱電、裝潢、泥作、線上商城；手機左右滑動 | 570／500 | 首頁；服務項目頁最上方 |
| 3 | 為什麼選擇我們 | 一條龍統包、透明報價、準時完工、保固售後（深藏青色帶） | 380／540 | 首頁服務卡片下方 |
| 4 | 施工流程時間軸 | 諮詢→勘查→報價→施工→驗收→保固 | 340／580 | 服務項目頁 |
| 5 | 施工前後對比滑桿 | 拖曳比較，可放多組案例切換 | 560／610 | 施工實績頁最上方；首頁一組精選 |
| 6 | 客戶評價輪播 | 星等、地區、工程類型，自動輪播 | 400／380 | 首頁；施工實績頁 |
| 7 | 精選商品 | 3–6 項商品卡片，按鈕連到賣場（4 項最省高度） | 590／650 | 線上商城頁最上方 |
| 8 | 常見問題手風琴 | 點一下展開答案（高度以展開一題計算） | 640／630 | 服務項目頁；聯絡我們頁 |
| 9 | 聯絡按鈕列 | 撥打電話、LINE 加好友、免費估價 | 200／340 | 每一頁最下方 |
| 10 | 公告／優惠橫幅 | 自訂公告、季節活動 | 200／300 | 首頁，需要時才放 |

所有區塊都符合以下限制：CSS 與 JS 寫在同一段、不含 `<html>`／`<head>`／`<body>`、不使用 `position: fixed` 與 `localStorage`、不操作上層頁面、只載入 Google Fonts（Noto Sans TC）、寬度 100% 自適應、所有連結都有 `target="_blank"`。

## 網站規劃

編輯器左邊的「網站規劃指南」有完整內容，而且會自動帶入你填的店名、電話、服務區域。內容包括：

- 協作平台頁面架構（首頁、服務項目、施工實績、線上商城、聯絡我們）與各頁區塊擺放順序
- Google 估價表單建議欄位
- 網站名稱、頁面標題、自訂網址等 SEO 設定
- 建議拍攝的照片清單
- 照片網址取得方式（Google 雲端硬碟：`https://lh3.googleusercontent.com/d/檔案ID`）
